## Snake and Ladder Problem – Use Cases

UC1 – Initialize Player Position to 0  
UC2 – Roll the Die (Generate Random Number between 1–6)  
UC3 – Check Game Option (No Play, Ladder, Snake)  
UC4 – Move Player Forward if Ladder Occurs  
UC5 – Move Player Backward if Snake Occurs  
UC6 – Ensure Player Position Does Not Go Below 0  
UC7 – Ensure Player Position Does Not Exceed 100  
UC8 – Repeat Game Till Player Reaches Winning Position (100)  
UC9 – Count Number of Dice Rolls to Reach the Winning Position  
UC10 – Two Player Game Simulation
